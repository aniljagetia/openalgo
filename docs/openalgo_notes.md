# Findings that change the signal design

Probed live against `https://algo.dhanhub.com` (Arrow) on 2026-09-09,
NIFTY spot 23635.10, prev close 23779.15, nearest weekly expiry `15SEP26`.

## 1. 🔴 The index has NO volume and NO OI — VWAP must use futures

`history` for `NIFTY` on `NSE_INDEX` returns 375 clean 5-minute candles, but
**every candle has `volume: 0` and `oi: 0`** — indices do not trade. The same
call for **`NIFTY29SEP26FUT` on `NFO` returns volume and OI on all 231 candles**
(e.g. `volume: 40495`, `oi: 17886635`).

**Consequence:** the spec's *"price vs VWAP"* technical signal **cannot be
computed on the index**. VWAP is a volume-weighted mean; with zero volume it is
undefined. VWAP must be computed from the **near-month future**, while EMA/RSI/
Supertrend/ORB can stay on the index. Futures OI is a free bonus signal.

Futures symbol is built from the futures expiry list (a *different* call —
`instrumenttype: "futures"` returns `29-SEP-26`, not the weekly options dates):
`"NIFTY" + expiry.replace("-","").upper() + "FUT"`.

## 2. 🔴 `prev_oi` is absent — OI change needs stored snapshots

Legs carry `oi` but never `prev_oi`. Buildup classification (LB/SB/SC/LU) needs
an OI *direction*, so the collector must persist snapshots and diff consecutive
ones. **The 15/30/60-minute OI-change signal is blank until the collector has
been running that long** — it cannot be back-filled at startup.

`prev_close` **is** present per leg, so the price half of the classifier works
from the first tick.

## 3. IV and greeks are real and per-leg — no local solver needed

`with_greeks=True` returns populated `implied_volatility`, `delta`, `gamma`,
`theta`, `vega` at no extra broker call. CE and PE IV differ on **29 of 31
strikes**, converging only at ATM (correct put-call parity), so the spec's
**IV-skew signal is computable**. The spec's local Black-Scholes /
Newton-Raphson solver is **not required**.

Caveat: deep-ITM legs return `implied_volatility: 0` (e.g. 22900 CE) — treat
**0 as "no IV", not as zero volatility**, or the smile and any skew average
will be dragged down.

## 4. `forward_price` is supplied — free synthetic future

The chain response includes `forward_price: 23696.55` against spot `23635.10`
(a ~61-point premium) plus `underlying_prev_close`, `expiry_ts` and `server_ts`.
Futures premium/discount needs **no** extra quote call.

## 5. Index quotes are LTP-only

`quotes` on `NSE_INDEX` returns only `ltp` and `prev_close`; `open`, `high`,
`low`, `bid`, `ask`, `volume` are all `0`. **INDIAVIX is quotable** (`ltp: 11.23`,
`prev_close: 11.16`) so the volatility signal has its input, but intraday
high/low for the opening-range breakout must be derived from **history candles**,
not from the quote.

## 6. Strike count

`strike_count: 15` returns **31 strikes** (15 either side + ATM), ATM `23650`.
